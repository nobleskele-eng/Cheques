## Methods that work
- Discovery: Douyin video page "推荐视频" (recommended) lists, seeded from clips Vyx liked; charm accounts' profile pages. Keyword search is poor (songs/news/filler); if used: `?type=video&sort_type=0&publish_time=7` (最多点赞+一周内 starves results).
- Douyin/TikTok video ID >> 32 = post time (UTC). Douyin pages show the viewer's local time.
- Detail JS: in page text find line starting '发布时间' at i → likes t[i-5], comments t[i-4], saves t[i-3], shares t[i-2], caption t[i-6], author t[i+1], fans t[i+2]. Video dims via video.videoWidth/Height; seek currentTime=0.05 for frame 1.
- Download (Option B; yt-dlp gets 403): logged-in browser pane → pick top quality in the player's 智能 menu → read video.currentSrc → `curl.exe -L -H "Referer: https://www.douyin.com/"` → inbox\pNN <content>.mp4 → precheck → log row.
- Reposts: same first frame + same length across accounts → earliest poster is the owner. Shared lyric captions ≠ same footage.
- TikTok checks: profile grid only; Popular tab sort; never curl TikTok pages (WAF challenge).
- Limits: ~20–30 Douyin page loads and ~15 logged-out TikTok profile loads per session before throttling. Stop on the first error; don't retry in a loop.
- Profile sweep method: on a profile, eval the grab script (scroll + collect a[href*=/video/] with likes + cover img) then draw a fixed black overlay of the top 18 covers with like labels and screenshot at scale 0.7 — one image per account. Only the first ~21 posts load (scroll does not page), pinned hits included. Store the script in localStorage on douyin.com and `eval(localStorage.__gsrc)` on each page to avoid resending it.
- 18 Oct 2nd session: keyword search (chasethemoment) and recommended lists returned filler (Tesla/news/AI) after ~20 loads — search throttle persists across sessions on the same day; profile pages still loaded.
- Collision dHash method (19 Oct): on douyin.com, hash each candidate's frame 1 (9x8 dHash + mirrored). On a TikTok grid, collect covers back to the oldest candidate date, reload each cover with crossOrigin=anonymous (tiktokcdn allows it; covers are 1080x1920), hash, flag Hamming ≤14, then compare flagged pairs by eye. Refs are stored in tiktok.com localStorage __refs, script in __c. Only catches covers that are frame 1.
- Token savings: small zooms (scale 0.4), browser_batch 2–4 pages per call, compact JS returns, pre-filter by likes/date/caption before detail pages, skip obvious rejects, start a fresh session per search round (this file + memory carry the context).
